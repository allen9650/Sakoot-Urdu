# 3D Character Model Placement

Place your 3D GLTF/GLB model file here:
`character.glb`

When `character.glb` is placed in this folder, the website's `InteractiveCharacter` component will automatically detect and load the 3D version using `@react-three/fiber` and `@react-three/drei`, preserving cursor head-tracking and idle animations.

In the absence of a `.glb` model, the website smoothly runs the high-fidelity 2.5D interactive character with real-time ocular tracking and procedural blinking.
